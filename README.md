# Omar Farooq Portfolio

A responsive developer portfolio built with plain HTML, CSS and JavaScript so it can be deployed almost anywhere.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Customize
1. Replace the email in `index.html`.
2. Replace the GitHub and LinkedIn links.
3. Add your resume link.
4. Update project descriptions and links.
5. Add your own profile photo if desired.

## Deploy
This is a static site and can be deployed to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any normal web server.
